# marginalia-digital-journal
A full-stack digital journaling application with user authentication, mood tracking, searchable journal entries, favorites, tags, daily streaks, and monthly statistics.
## ✨ Features

- 🔐 User registration and login
- ✍️ Create and edit journal entries
- 🗑️ Delete journal entries
- ⭐ Favorite entries
- 🔍 Search journal entries
- 🏷️ Tag-based organization
- 😊 Mood tracking
- 🔥 Daily writing streak
- 📅 Monthly entry calendar
- 📊 Monthly mood statistics
- 👤 User profile
- 📱 Responsive interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- REST API
- Backend
- Database
## 📌 Key Features

### 🔐 Authentication
Users can create an account and securely sign in to access their personal journal. 

### 📝 Journal Management
Users can create, edit, view, favorite, and delete journal entries with titles, content, moods, tags, and dates. 

### 😊 Mood Tracking
Entries can be categorized into moods such as Joyful, Calm, Neutral, Excited, Anxious, Sad, and Angry.

### 🔎 Search & Filtering
Journal entries can be searched and filtered by mood, tags, and favorites.

### 🔥 Streak Tracking
The application tracks the user's consecutive writing days and displays the current streak.
